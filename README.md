Это официальный сайт стримера Годня, на нём можно найти основную информацию, просмотренный контент и имеющиеся заказы.

## Возможности
#### Основные
- Навигация по просмотренному контенту и заказам
- Добавление тайтлов и заказов в избранное
- Просмотр записей в плеере прямо на сайте
- Просмотр текущего расписания и прошлых стримов
#### Функции
- Поиск тайтлов/заказов по триграммам
- Поиск заказов по никам
#### Настройки
- Переключение светлой/тёмной темы
- Выбор соотношения сторон окна
